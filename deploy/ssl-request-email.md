## Одоогийн байдал (шалгаж тогтоосон)

| Зүйл | Утга |
|---|---|
| Домэйн | `manage.dornogovi.gov.mn` → 202.37.109.67 (A бичлэг зөв) |
| Сервэр | mcloud.gov.mn дэх `manage-dornogovi` виртуал сервэр |
| Одоогийн сертификат | **Өөрөө гарын үсэг зурсан** (issuer = CN=manage.dornogovi.gov.mn), 2027-08-24 хүртэл |

## Захидлын агуулга

Эрхэм хүндэт Үндэсний дата төвийн хамт олон,

Дорноговь аймгийн Засаг даргын Тамгын газраас mcloud.gov.mn үүлэн үйлчилгээнд
байрлуулсан `manage.dornogovi.gov.mn` системийн SSL сертификатыг албан ёсны,
итгэмжлэгдсэн сертификатаар солих хүсэлт гаргаж байна.

Одоо тус систем нь өөрөө гарын үсэг зурсан (self-signed) сертификаттай тул
хэрэглэгчид «Not secure / Аюулгүй биш» анхааруулгыг байнга алгасаж ороход
хүрч байна. Энэ нь MITM халдлагын эрсдэл үүсгэж, албан хаагчдын нэвтрэх
мэдээлэл алдагдах эрсдэлтэй.

Дараах **гурван хувилбарын аль нэгээр** шийдвэрлэж өгөхийг хүсье:

**Хувилбар 1 — TCP 80 портыг нээх (хамгийн энгийн):**

`202.37.109.67` хаягийн TCP 80 портыг интернэтээс (0.0.0.0/0) нээж өгвөл бид
Let's Encrypt-ийн үнэгүй сертификатыг өөрсдөө суулгаж, 90 хоног тутам
автоматаар шинэчлэгдэхээр тохируулна. Порт 443 аль хэдийн нээлттэй байна.
Порт 80 нь зөвхөн HTTPS руу чиглүүлэх болон сертификат баталгаажуулалтад
ашиглагдана.

**Хувилбар 2 — DNS-ээр баталгаажуулах:**

Порт нээх боломжгүй бол `_acme-challenge.manage.dornogovi.gov.mn` нэртэй TXT
бичлэгийг бидний өгсөн утгаар үе үе (90 хоног тутам) нэмж өгөх, эсвэл уг
дэд домэйныг бидний DNS сервэр рүү delegate хийж өгнө үү. Ингэснээр порт
нээлгүйгээр сертификат авах боломжтой болно.

**Хувилбар 3 — НДТ-ээс сертификат олгох:**

Хэрэв Үндэсний дата төв нь .gov.mn домэйнд зориулсан сертификат олгодог
журамтай бол уг журмын дагуу `manage.dornogovi.gov.mn` домэйнд сертификат
олгож өгнө үү. Бидэнд `.crt` (болон завсрын chain) + `.key` файлыг ирүүлбэл
бид сервэрт суулгана. Шаардлагатай бол CSR-ийг бид үүсгэж илгээнэ.

Аль хувилбар танай журамд нийцэхийг зөвлөж өгвөл бид дагаж ажиллах болно.

## Дотоод тэмдэглэл (илгээхгүй)

**Хувилбар 1 хэрэгжвэл, серверт ажиллуулах команд:**

```bash
sudo clpctl lets-encrypt:install:certificate --domainName=manage.dornogovi.gov.mn
```

**Хувилбар 2 хэрэгжвэл:**

```bash
# acme.sh суулгаад DNS-01 горимоор
curl https://get.acme.sh | sh
~/.acme.sh/acme.sh --issue --dns -d manage.dornogovi.gov.mn --yes-I-know-dns-manual-mode-enough-go-ahead-please
# → гарсан TXT утгыг НДТ-д илгээж нэмүүлнэ, дараа нь:
~/.acme.sh/acme.sh --renew -d manage.dornogovi.gov.mn --yes-I-know-dns-manual-mode-enough-go-ahead-please
```

**Хувилбар 3 (эсвэл 2)-ын дараа сертификатыг суулгах:**

```bash
sudo clpctl site:install:certificate \
  --domainName=manage.dornogovi.gov.mn \
  --privateKey=/root/manage.key \
  --certificate=/root/manage.crt \
  --certificateChain=/root/chain.crt
```

**Түр арга (эдгээрийг хүлээх хугацаанд):** одоогийн self-signed сертификатыг
байгууллагын компьютеруудад Group Policy-оор «Итгэмжлэгдсэн үндсэн гэрчилгээ»
болгож тараавал дотоод хэрэглэгчдэд анхааруулга харагдахгүй болно. Гэхдээ
гаднаас (гэр, томилолт) хандах үед анхааруулга хэвээр үлдэнэ.
