# Нэвтрэх хуудасны зурагнууд

Эдгээр файлыг энд хийхэд нэвтрэх хуудас автоматаар ашиглана — код засах
шаардлагагүй. Файл байхгүй бол хуудас гуйвахгүй, орлуулах хувилбар харагдана.

| Файл | Юу вэ | Зөвлөмж |
|---|---|---|
| `emblem.png` | Дорноговь аймгийн сүлд | Тунгалаг дэвсгэртэй PNG, 512×512 орчим |
| `building.jpg` | Нутгийн удирдлагын ордон | Өргөн хэлбэртэй, 1600×900-аас багагүй |

- `emblem.png` байхгүй бол — энгийн хөх дугуй + соёмбо харагдана
  ([StateEmblem.vue](../../resources/js/Components/StateEmblem.vue))
- `building.jpg` байхгүй бол — зөвхөн хөх градиент дэвсгэр үлдэнэ
  (баруун талын самбар)

Зургийг сольсны дараа `git add public/images && git commit && git push` хийхэд
сервер 2 минутын дотор өөрөө шинэчилнэ.
