# Manage Dornogovi — нэвтрэлтийн өргөтгөл

Платформд хадгалсан нэвтрэх мэдээллээр төрийн системүүдийн нэвтрэх маягтыг
автоматаар бөглөж, илгээнэ. Өргөтгөлгүй үед платформ нь нууц үгийг санах ойд
хуулаад системийн нэвтрэх хуудас руу шилжүүлдэг — өргөтгөлтэй үед энэ алхам
шаардлагагүй болно.

## Яагаад өргөтгөл хэрэгтэй вэ

Вэб хуудас өөр домэйны маягтыг бөглөж чадахгүй — энэ бол browser-ийн үндсэн
хамгаалалт (same-origin policy). Мөн эдгээр системүүдийн нэвтрэлт нь энгийн
маягтын POST биш:

| Систем | Нэвтрэлт |
|---|---|
| Төрийн ERP | Nuxt SPA → JSON API |
| Шилэн данс | Ant Design SPA |
| Үнэлгээ | `action="javascript:;"` → JS |
| Төрийн шуудан | Zimbra, `login_csrf` токентой |

Тиймээс сервер талаас нэвтрүүлэх боломжгүй. Өргөтгөл нь тухайн хуудсан дотор
ажилладаг тул эдгээр бүх тохиолдолд ажиллана.

## ДАН-аар нэвтрэх

ДАН (Үндэсний танилт, нэвтрэлтийн систем)-ээр нэвтэрдэг систем дээр админ
тохиргоонд «ДАН-аар нэвтэрдэг» гэж тэмдэглэсэн бол албан хаагч нэвтрэх
мэдээлэлдээ **ДАН-аар нэвтрэх** сонголтыг сонгож, регистрийн дугаар болон ДАН
нууц үгээ хадгална.

`dan-autofill.js` нь ДАН-ы нэвтрэх хуудсанд:

1. «Нэг удаагийн код» табыг сонгоно
2. «Регистрийн дугаар» дэд табыг сонгоно
3. Регистрийн 2 үсгийг эхний хоёр талбарт, 8 оронг дугаарын талбарт бөглөнө
4. ДАН нууц үгийг бөглөнө
5. «Нэвтрэх» дарж баталгаажуулах кодыг утас руу илгээнэ
6. Кодын талбарт фокус тавьж өгнө

**Баталгаажуулах кодыг хэрэглэгч өөрөө оруулна.** ДАН-ы нэг удаагийн кодыг
тойрох боломжгүй бөгөөд өргөтгөл үүнийг оролдохгүй.

### «Энэ төхөөрөмжийг санах»

Нэвтрэх мэдээллийг хадгалахдаа энэ сонголтыг тэмдэглэвэл өргөтгөл нь регистр,
нууц үгийг тухайн компьютерийн `chrome.storage.local`-д үлдээнэ. Дараа удаа
ДАН-ы хуудсыг нээхэд платформыг дамжихгүй, санг нээлгэхгүйгээр шууд бөглөнө.

Анхаар:

- Мэдээлэл тухайн төхөөрөмж дээр браузер хаагдсан ч үлддэг (энгийн горимд
  зөвхөн session санах ойд, 90 секунд хадгалагддаг).
- Хамтын хэрэглээний компьютерт **бүү асаа**.
- Устгах бол өргөтгөлийн popup дээрх «Төхөөрөмжид санасныг устгах» дарна.
- ДАН нэг удаагийн код дахин асуух эсэхийг ДАН өөрөө шийднэ — өргөтгөл түүнд
  нөлөөлөхгүй. Ихэвчлэн ДАН-ы session cookie хүчинтэй байвал дахин асуухгүй.

## Суулгах

1. Системээс «Өргөтгөл татах» дарж **manage-dornogovi-extension** хавтсыг авна
   (хавтас сонгох эсвэл ZIP татаж задаана).
2. Хавтас доторх **install.bat**-ыг ажиллуулна — эсвэл `chrome://extensions` нээнэ.
3. **Developer mode** асаана.
4. **Load unpacked** дарж энэ хавтсыг сонгоно.
5. Өргөтгөл жагсаалтад гарч ирнэ.

Дэлгэрэнгүй: `СУУЛГАХ.txt`

Firefox дэмжигдээгүй (Manifest V3 + `chrome.storage.session` ашигласан).

## Ашиглах

Ямар нэг нэмэлт үйлдэл шаардахгүй. Платформ дээр систем дарахад:

1. Платформ нэвтрэх мэдээллийг өргөтгөлд шилжүүлнэ
2. Систем рүү шилжинэ
3. Өргөтгөл нэвтрэх маягтыг олж бөглөөд илгээнэ

SPA дээр маягт хожуу зурагддаг тул 20 секунд хүртэл хүлээж, гарч ирмэгц бөглөнө.

## Аюулгүй байдал

- Мэдээлэл `chrome.storage.session`-д хадгалагдана — **диск дээр бичигдэхгүй**,
  browser хаагдахад устана
- **90 секундын дараа** хүчингүй болно
- **Нэг удаа** ашиглагдаад шууд устгагдана
- Зөвхөн `http://localhost/manage.dornogovi.gov.mn/` хаягаас ирсэн мэдээллийг
  хүлээн авна (`background.js` дотор шалгадаг)
- Мэдээллийг зөвхөн тухайн зорилтот домэйн дээр л бөглөнө

## Шинэ систем нэмэх

`manifest.json` доторх `host_permissions` болон хоёр дахь `content_scripts`
блокийн `matches` жагсаалтад шинэ домэйныг нэмнэ, дараа нь
`chrome://extensions` дээр өргөтгөлийг **Reload** дарна.

## Продакшн дээр гаргах үед

`manifest.json` болон `background.js` доторх `http://localhost/manage.dornogovi.gov.mn/`
хаягийг жинхэнэ домэйноор (`https://manage.dornogovi.gov.mn/`) солино. Нэвтрэх
мэдээлэл дамждаг тул продакшн дээр заавал **HTTPS** байх ёстой.
